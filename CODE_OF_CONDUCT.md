# Contributor Covenant Code of Conduct

## Our pledge

Everyone contributing to this project - via issues, pull requests,
discussions or code review - is expected to keep the discussion technical,
honest and respectful.

## Our standards

**Positive behavior:**

- Critique the data, the code and the claims - not the person.
- Assume good faith, especially when someone reports that the engine missed
  or invented a variant. Wrong extractions are bugs to fix, not failures to
  mock.
- Cite literature when making scientific claims about variants.

**Unacceptable behavior:**

- Harassment, personal attacks or discriminatory language.
- Publishing others' private information.
- Presenting the tool's output as clinical advice.

## Enforcement

Project maintainers may remove, edit or reject contributions that violate
this Code of Conduct. Reports can be made privately through GitHub by
contacting the repository owner.
